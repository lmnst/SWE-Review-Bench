# Artifacts MANIFEST

Per-file description, reproducibility command, and public-release
recommendation for every artefact generated by the project. Six
sections, in the spec-required order:

1. Round 1 baseline files (`outputs/`)
2. Round 2 diagnostic files (`outputs/round2/`)
3. H-lite derived files (`outputs/round2/h_lite/`)
4. `docs/` files
5. `repro/` files
6. `tests/` files

**`public_ok` legend.** `yes` = Task 1 (`outputs/round2/h_lite/safety_audit.md`)
cleared the file or the file is provably free of secrets / oracle
content by construction. `no` = file should not be published. `needs_review`
= human inspection required before publishing.

Files under `.cache/` are intentionally **not** listed in this
manifest. They are gitignored by policy (`.gitignore` covers
`.cache/`) and the `.cache/.../raw/` subdirectories hold full
verbatim LLM responses that have not been individually safety-audited.

The empty placeholder file `outputs/.gitkeep` is also not listed.

## 5. `repro/` files

Cache-safe reproduction entrypoint. Default-mode `bash repro/run.sh`
costs $0 (runs the leakage pytest suite and reads existing CSVs);
the uncached replay path is intentionally not wired so that no run
can silently spend money.

| path | description | reproducible_from | public_ok |
|---|---|---|---|
| `repro/run.sh` | One-command cache-safe reproduction: warns / checks env / checks lock / runs leakage pytest / prints Round 1 + Round 2 headline tables with Wilson CIs. No paid API call by default; refuses `RUN_PAID_REPLAY=1` because the orchestrator does not expose a fail-on-cache-miss flag. | Hand-authored. | yes |
| `repro/MANIFEST.md` | Per-file `repro/` description and step to output map; lists the from-scratch-with-paid-calls recipe. | Hand-authored. | yes |
| `repro/requirements.lock` | `pip freeze` of the project's Python environment (Python 3.9.12, 92 packages) at the time of the pilot. | `pip freeze > repro/requirements.lock` from the project venv. | yes |
